A warning label for a time machine, phrased like a genuine safety notice — one traveller stepped on a butterfly, and now his grandson is a parking meter.

## Entry

> WARNING: Do not step on butterflies. One traveller did, and now his grandson is a parking meter.

## How it works

`main.py` (Python 3 standard library only) writes the entry text above to `entry.txt` in the output directory given by the `MAKEFUN_OUTPUT_DIR` environment variable, falling back to `/output`. The file contains exactly the one-line entry — 96 characters, 96 bytes, no trailing newline.
